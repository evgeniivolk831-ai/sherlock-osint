# Sherlock OSINT — самостоятельная альтернатива

Мобильное веб-приложение с чёрно-бирюзовым интерфейсом. Каталог `data.json` загружается пользователем и используется backend как источник URL-шаблонов и правил проверки.

## Запуск
1. Установите Node.js 18 или новее.
2. В папке проекта выполните `npm install`.
3. Запустите `npm start`.
4. Откройте `http://localhost:3000`.

Для публикации можно импортировать проект в Bonto, Render или другой Node.js-хостинг. Бесплатные тарифы и ограничения зависят от провайдера.

## Каталог Sherlock
Скачайте официальный `data.json` из репозитория Sherlock и загрузите его кнопкой «Установить data.json». Каталог содержит правила сайтов, а не базу пользователей.

Поддерживаются правила `message`, `status_code`, `response_url`, `errorMsg`, `errorCode`, `regexCheck`, `urlProbe`, `request_method`, `headers` и `request_payload` (ограниченный набор HTTP методов). Неподдерживаемые методы и неопределённые ответы отображаются как `unknown`. Это совместимый упрощённый движок, а не полный порт Python Sherlock.

## Ограничения
- Только страницы, доступные анонимно по HTTPS.
- CAPTCHA, антибот, авторизацию и ограничения сайтов приложение не обходит.
- Метаданные (`title`, `og:title`, `description`, `og:description`, `og:image`) извлекаются только из общедоступного HTML-ответа.
- Не собираются телефоны, адреса, банковские данные, государственные идентификаторы, пароли, утечки и закрытые базы.
- Результат может быть `unknown` из-за защиты сайта, блокировок, динамического контента или ограничений хостинга.
- Пользуйтесь инструментом только законно и уважайте правила сайтов.

## Примечание по размещению
Для публичного доступа нужен хостинг Node.js с исходящими HTTPS-запросами. На бесплатных тарифах могут быть лимиты CPU, памяти, трафика и времени работы.


## Установка на Android как приложение (PWA)

Интерфейс поддерживает установку на главный экран и офлайн-кэш оболочки. После публикации откройте HTTPS-адрес в Chrome на Android и выберите меню ⋮ → «Установить приложение».

## Бесплатное размещение на Render

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/evgeniivolk831-ai/sherlock-osint)

Blueprint использует существующий `render.yaml` и бесплатный Web Service. Бесплатные сервисы Render автоматически засыпают после 15 минут бездействия и просыпаются при следующем запросе; первый запрос после простоя может быть медленным. Это не круглосуточный режим без задержек.
